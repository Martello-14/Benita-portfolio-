# Benita Williams — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `styles.css` — layout, colours, typography, and responsive styling
- `script.js` — mobile navigation and automatic footer year

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with your preferred email address.
3. Review the wording and make sure it accurately reflects your current experience.
4. This starter portfolio labels the portfolio website as a project in progress. Update that status only after you've tested and published it.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open the repository's **Settings** → **Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish. The website link will usually look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
7. Open the link and test it on your phone.
